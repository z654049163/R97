# An Empirical Study on the Effects of Obfuscation on Static Machine Learning-Based Malicious JavaScript Detectors

- **元数据（CrossRef 按标题检索核验，2026-10-12）**：Kunlun Ren, Weizhong Qiang, Yueming Wu, Yi Zhou, Deqing Zou, Hai Jin（华中科技大学）；**ISSTA 2023**；DOI `10.1145/3597926.3598146`；pp. 1420–1432。
- **文献画像**：量化混淆对"基于静态特征的 ML 恶意 JS 检测器"的破坏：静态观测被混淆扰动后，检测器判定大面积翻转。ISSTA 顶会、JS 专属、与 R97 同属"混淆 vs 静态分析鲁棒性"主题。
- **机理审视**：结构平行——它研究"混淆扰动静态特征 → 分类决策翻转"，R97 的混淆不变性研究"混淆扰动静态绑定/观测 → 折叠决策迁移"。关键差异有两点：①它测的是检测器准确率退化（安全负向），R97 测的是折叠决策迁移方向（实测全部落在安全方向 FOLD→UNKNOWN，0 不安全折叠）；②它无运行时/宿主维度，R97 的差分实体判据把"环境物理事实不变"作为不变量的锚。
- **可借鉴点**：**写作引用**（Related Work/Discussion）：把 R97 放进"混淆 vs 静态分析鲁棒性"脉络——检测器退化是脆弱性的证据，R97 的 0 不安全折叠是该脉络里第一个"守门安全"结论；其"静态特征被混淆扰动"的量化方法可对照引用。
- **反衬点**：检测器中心（分类翻转），不做折叠决策；无跨宿主维度；无技术移植件。
